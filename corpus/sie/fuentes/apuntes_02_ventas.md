# Sistemas Integrados Empresariales – Módulo de Ventas: apuntes de clase

## 1. Qué hace el módulo de Ventas
El módulo de Ventas se encarga de todo el proceso de salir al mercado para conseguir clientes y concretar la compra. Se apoya en la información generada por Marketing y requiere el desarrollo de habilidades clave. Ventas también es responsable de mantener una base de datos de sus clientes.

## 2. Habilidades fundamentales del vendedor
Las 4 habilidades fundamentales de ventas son: comunicación, negociación, convencimiento y persuasión.
- **Comunicación:** transmitir la propuesta de valor de forma clara.
- **Negociación:** acordar términos beneficiosos para ambas partes.
- **Convencimiento:** razonar lógicamente para mostrar las ventajas del producto.
- **Persuasión:** apelar a las necesidades y emociones del cliente para motivar la compra.
La diferencia entre convencimiento y persuasión: el convencimiento usa la razón y la lógica; la persuasión apela a las necesidades y emociones.

## 3. Embudo de ventas (AIDA)
El proceso de ventas sigue un embudo diseñado para guiar al cliente potencial desde el primer contacto hasta la compra final. AIDA significa Atención, Interés, Deseo y Acción.
- **Atención:** captar el interés inicial del cliente.
- **Interés:** generar curiosidad sobre el producto o servicio.
- **Deseo:** fomentar la necesidad y el anhelo por la solución ofrecida.
- **Acción:** impulsar al cliente a realizar la compra.

## 4. Flujo de cierre de venta
Una vez que el cliente decide comprar, se inicia un proceso formal documentado: cotización, orden de pedido y verificación de stock.
- **Petición de producto, proforma o cotización:** documento inicial que detalla la oferta. Incluye la información del cliente (nombre, código), los detalles del producto (descripción, cantidad, precio unitario) y las condiciones comerciales (descuentos, total y validez de la oferta por "n" días).
- **Orden de pedido:** si el cliente acepta la cotización, la venta se formaliza con una orden de pedido. Este documento funciona como un acuerdo o pacto y especifica las formas de pago. De manera opcional, en este paso se pueden ofrecer productos relacionados o alternativos.
- **Verificación de stock:** una vez aceptada la orden, se verifica la disponibilidad del producto.

## 5. Qué pasa según haya o no stock
- **Sí hay stock:** se notifica al módulo de Almacén para que prepare el producto para su retiro o envío, y luego se procede a la facturación.
- **No hay stock:** la orden se deriva al módulo de Producción para fabricar el producto.
