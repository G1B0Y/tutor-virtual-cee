# Sistemas Integrados Empresariales – Módulo de CRM: apuntes de clase

## 1. Qué es el CRM
El CRM es el sistema central que recopila y gestiona toda la comunicación e información relacionada entre el cliente y el producto. Su objetivo principal es usar esta data para entender los detalles del cliente e implementar estrategias efectivas.

## 2. Funciones principales del CRM
Las funciones principales del CRM son: la centralización de datos, la gestión de interacciones (captación y reclamos) y el proceso de post-venta.
- **Centralización de datos:** guarda y organiza toda la data del cliente (y de los "no clientes") para conocer sus detalles y necesidades. La información recopilada es fundamental para que Marketing pueda implementar nuevas estrategias.
- **Captar clientes potenciales:** almacena datos de prospectos para futuras acciones comerciales.
- **Atender reclamos:** cuando un cliente reporta un problema (por ejemplo, un producto defectuoso), el CRM recepciona el reclamo y lo deriva al módulo correspondiente (Producción, Calidad, etc.). Una vez que ese módulo genera una respuesta o solución, esta regresa al CRM para comunicarla al cliente.

## 3. Proceso de post-venta
La post-venta se encarga de verificar el desempeño del producto o servicio después de la venta, para asegurar la calidad y la experiencia del cliente.
Realiza encuestas de satisfacción para validar la atención recibida y medir la lealtad del cliente (por ejemplo, el NPS, Net Promoter Score).

## 4. Conceptos adicionales
- **Reportes (hojas):** el sistema debe ser capaz de generar informes a partir de la data.
- **Base de datos:** es el soporte tecnológico donde se almacena toda la información.
- **Condiciones (flujo):** son las reglas y decisiones que guían los procesos (por ejemplo, la verificación de stock).
